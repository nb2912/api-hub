# 🎓 Student API Hub

An open-source ecosystem for students to publish, discover, and test APIs.

## 🚀 Features
- **API Registry**: Categorized listing of community APIs.
- **API Playground**: Live testing proxy for instant integration.
- **Developer Dashboard**: Manage keys and track analytics.
- **Secure**: JWT authentication and encrypted API keys.

## 🛠️ Setup
1. **Backend**: `cd backend && pip install -r requirements.txt && uvicorn main:app --reload`
2. **Frontend**: `cd frontend && npm install && npm run dev`
3. **Docker**: `docker-compose up --build`

## 📂 Structure
- `/backend`: FastAPI, SQLAlchemy, Pydantic.
- `/frontend`: Next.js 14, Tailwind CSS, Framer Motion.
- `/docs`: Documentation and walkthroughs.
